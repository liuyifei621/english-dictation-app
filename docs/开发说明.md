# 英语默写App开发说明

当前原型使用 Expo/React Native，一套代码同时生成 Android 和 iOS 资源。

## 已实现

- 中文 → 英文、英文 → 中文两种默写模式
- 顺序版、乱序版
- 可设置每题停顿秒数
- 可设置每个词播报 1—4 遍
- 播报完成后开始停顿，停顿结束自动进入下一题
- 点击停止后才显示英文、词性和中文释义
- 文本词库解析与自动去重

## 本地运行

```text
pnpm install
pnpm start
```

## 打包检查

```text
pnpm exec expo export --platform android
pnpm exec expo export --platform ios
```

## 下一步

将 Word、PDF、图片上传后的内容统一送入文档解析/OCR服务，提取英文、词性和中文释义；再加入词典音频缓存，减少重复联网请求。

正式发布前需要：

1. 把 `server` 部署到有固定 HTTPS 域名的云服务。
2. 将 `EXPO_PUBLIC_EXTRACTION_API_URL` 设置为该域名的 `/extract` 地址。
3. 使用 Expo/EAS 生成 Android 和 iOS 安装包。
